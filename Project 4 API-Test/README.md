# Тестирование 

В этом репозитории содержатся тесты для сервиса сокращения ссылок, разработанного в **ДЗ 3**.

Код из **ДЗ 3** остался без изменения, крому тех вещей, которые я упоминал в README для **ДЗ 3** - поменял комментарии в файлах database.py и cache.py, чтобы запускать локально, вместо размещения на render.


В проекте реализованы:

- Unit и API тесты с использованием **pytest**
- Проверка покрытия кода тестами с помощью **coverage**
- Нагрузочное тестирование с использованием **Locust**
- HTML‑отчёт с визуализацией покрытия тестами

---

# Покрытие тестами

Покрытие кода тестами рассчитывается с помощью инструмента **coverage**.

HTML‑отчёт с визуализацией покрытия находится в репозитории по пути:

```
Project 4 API-Test/htmlcov/index.html
```

Файл можно открыть напрямую в браузере и увидеть процент покрытия кода тестами.

Процент покрытия - 91%

# Запуск тестов

При необходимости установить зависимости:

```
pip install -r requirements.txt
```

Запуск тестов с подсчётом покрытия:

```
coverage run -m pytest tests
```

Вывод покрытия в терминале:

```
coverage report
```

Генерация HTML‑отчёта покрытия:

```
coverage html
```

После выполнения команды отчёт будет доступен по пути:

```
htmlcov/index.html
```

# Нагрузочное тестирование

Для нагрузочного тестирования используется **Locust**.

Перед запуском Locust необходимо запустить приложение через Docker.

### 1. Сборка и запуск сервиса

```
docker compose up --build
```

После запуска API будет доступно по адресу:

```
http://localhost:8000
```

---

### 2. Запуск Locust

В отдельном терминале выполнить:

```
locust --host http://localhost:8000
```

После запуска откроется веб‑интерфейс Locust:

```
http://localhost:8089
```

В интерфейсе можно задать:

- количество пользователей
- скорость появления пользователей (spawn rate)

Нагрузочный тест моделирует:

- массовое создание коротких ссылок
- переходы по коротким ссылкам (redirect)
- обращения к API поиска
